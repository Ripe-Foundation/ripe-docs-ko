# 상환하고 출금하기

**1단계.** **Borrow** 페이지에서 Borrow 버튼 옆의 **Payback**을 누르세요. 부채가 있을 때만 이 버튼이 표시되고, 부채가 없으면 패널에 No Debt라고 표시됩니다. 대시보드에서는 같은 작업을 **Repay**라고 부릅니다. 이름만 다를 뿐 둘 다 같은 방식으로 작동합니다.

![처음 사용할 때 Approve가 표시된 상환 창](../.gitbook/assets/user-guide-10-payback-modal.png)

**2단계.** 자금 출처와 금액을 선택하세요. 두 가지 출처는 작동 방식이 다릅니다.

* **지갑에서 상환:** GREEN 또는 [sGREEN](../earning-and-rewards/01-sgreen.md)을 사용합니다. sGREEN은 GREEN으로 전환되어 부채 상환에 적용됩니다. 처음에는 버튼에 **Approve**가 표시됩니다. 토큰 사용 권한을 승인하면 Payback으로 바뀝니다. MAX 버튼은 부채 전액을 상환하고 초과분을 sGREEN으로 돌려줍니다.
* **안정화 풀 예치금에서 상환:** **Source** 토글을 바꾸면 Earn에 이미 예치한 sGREEN 또는 LP 토큰으로 바로 상환할 수 있습니다. 일반 상환 대신 [디레버리지](../core-protocol/05-deleverage.md)가 실행됩니다. 풀 포지션을 사용해 부채를 줄이며 별도의 승인이 필요하지 않습니다. 지갑을 건드리지 않고 부채를 정리하는 방법이며, 주식 토큰은 절대 사용하지 않습니다.

지불이 완료되는 즉시 부채 비율이 개선됩니다.

**3단계.** 담보를 꺼내려면 담보 표에서 해당 자산 행의 **-**를 누르세요. **+**는 예치, **-**는 출금입니다. 남은 부채를 뒷받침하는 데 필요하지 않은 자산은 작은 버퍼를 제외하고 출금할 수 있습니다. Ripe는 부채가 대출 한도 바로 아래에 머물도록 하므로 한도 끝까지 출금할 수는 없습니다. 전액 상환했다면 전부 출금할 수 있습니다. 청산 중인 포지션은 출금이 차단됩니다. 먼저 부채를 상환하거나 담보를 추가해 청산 상태에서 벗어나세요.

**4단계.** 지갑에서 거래를 확인한 다음 지갑 잔액을 확인하세요.
