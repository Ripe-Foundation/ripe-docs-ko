# Endaoment: 쉬지 않고 일하는 자금

모든 프로토콜에는 트레저리가 있습니다. 대부분은 수백만 달러를 가만히 보관합니다.

Endaoment는 모든 달러를 일하게 합니다. [본드](../governance-and-economics/03-bonds.md)와 [Reserve Engine](../governance-and-economics/04-reserve-engine.md) 배정 대금은 프로토콜 소유 자본이 됩니다. 거버넌스는 이 자본을 DeFi 전반에 배치해 수익, GREEN 유동성, [페그 방어](01-green-stablecoin.md)에 사용합니다. 단순히 보관하는 것이 아니라 성장하도록 만든 트레저리입니다.

> **실시간 조건은 온체인에 있습니다.** 활성화된 통합, 풀, PSM 설정은 배포 네트워크마다 다르고 시간에 따라 바뀝니다. 이 페이지의 모든 수치는 예시입니다. [Params](https://params.ripe.finance)가 최종 기준입니다.

## Endaoment가 존재하는 이유

대부분의 트레저리는 선택해야 합니다. 안전을 위해 준비금을 쉬게 두거나, 성장을 위해 자본을 운용합니다. Endaoment는 둘 다 합니다.

1. 수익 전략으로 **프로토콜 자산을 성장**시킵니다.
2. 기준 풀과 PSM에서 **GREEN을 방어**합니다.
3. **거버넌스의 지시에 따라 행동**합니다. 모든 운용은 제출된 온체인 트랜잭션입니다.
4. 다음 작업에 사용할 수 있도록 **수익을 계속 보유**합니다.

## 세 개 컨트랙트의 구조

```
┌─────────────────────────────────────────────────────────────┐
│                      ENDAOMENT 시스템                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌───────────────┐   ┌───────────────┐   ┌───────────────┐  │
│  │   Treasury    │   │   Endaoment   │   │      PSM      │  │
│  │    (Vault)    │◄──│  (Operator)   │──►│ (Peg Defender)│  │
│  └───────────────┘   └───────────────┘   └───────────────┘  │
│                                                             │
│    프로토콜 자산      스왑, LP, 수익,     GREEN ↔ 준비금    │
│    보관               페그 안정화          스테이블코인 $1  │
│                                             + 준비금 수익   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**볼트** — 자금이 보관되는 곳입니다. 운영자만 출금할 수 있습니다.

**운영자** — 두뇌 역할입니다. 스왑, 유동성, 수익 전략, GREEN Stabilizer를 실행합니다.

**페그 방어 장치** — GREEN을 준비금 스테이블코인과 $1에 교환하며, 남용을 막는 한도가 있습니다.

## 가치가 들어오는 곳

```
본드 / Reserve Engine 대금 → 트레저리 → 수익 및 유동성 → 프로토콜 강화
              ↑                                             ↓
              └──────────── 사용자 신뢰 향상 ←─────────────┘
```

본드 또는 Reserve Engine 배정에 지불된 모든 스테이블코인은 트레저리 자본이 됩니다. 본드는 구매 시 RIPE를 발행하고, Reserve Engine은 베스팅된 만큼만 발행합니다. 트레저리는 청산에서 안정화 풀이 지불한 GREEN이 아닌 자산과 디레버리지가 포지션에서 가져온 스테이블코인도 받습니다. 이 모든 자산은 DeFi에서 수익을 내고, GREEN 거래를 위한 유동성을 공급하고, 시장 스트레스 때 프로토콜을 뒷받침할 수 있습니다.

## 핵심 기능

### 1. 지능형 GREEN 안정화

**균형 규칙:** 같은 가치 기준으로 기준 풀의 GREEN과 페어 스테이블코인을 비교합니다. 더 무거운 쪽을 확인해 차이 전체가 아니라 일부를 이동합니다.

**GREEN이 약해질 때**(풀에 GREEN이 너무 많음):

* GREEN 유동성을 회수합니다.
* 기록된 풀 부채 한도 안에서 소각합니다.
* 풀의 균형이 회복되고 가격이 $1 쪽으로 움직입니다.

**GREEN이 강해질 때**(풀에 GREEN이 너무 적음):

* 트레저리가 보유한 GREEN부터 유동성으로 추가합니다.
* 나머지는 한도 안에서 발행하고 풀 부채로 기록합니다.
* 풀이 깊어지고 가격이 $1 쪽으로 움직입니다.

각 작업은 거버넌스가 제출하며 타이머로 자동 실행되지 않습니다. 트레저리의 순포지션이 악화되지 않을 때만 작업이 처리됩니다. Stabilizer는 페그를 방어하기 위해 트레저리의 가치를 희생하지 않습니다.

### 2. 페그 안정화 모듈(PSM)

슬리피지도 DEX의 복잡함도 없습니다. PSM은 GREEN과 배포 시 고정된 하나의 준비금 스테이블코인을 $1에 직접 교환합니다. 거버넌스가 활성화한 방향으로만 작동합니다.

* **GREEN 발행**: 준비금 스테이블코인을 예치하고 GREEN을 1:1로 받습니다. sGREEN을 요청한 경우, 발행량이 1 GREEN을 초과하면 전량이 sGREEN으로 래핑됩니다.
* **GREEN 상환**: GREEN 또는 sGREEN을 소각하고 준비금 스테이블코인을 1:1로 받습니다.

```
GREEN이 $1 아래인가요?
→ 차익거래자가 저렴한 GREEN 매수
→ PSM에서 준비금 스테이블코인 $1어치로 상환
→ 매수 압력으로 페그 회복

GREEN이 $1 위인가요?
→ 차익거래자가 준비금 스테이블코인 $1로 GREEN 발행
→ 시장에서 차익만큼 높은 가격에 매도
→ 매도 압력으로 페그 회복
```

**안전장치**

* 발행 및 상환의 주기별 한도
* 선택적 수수료와 통제된 출시를 위한 선택적 허용 목록
* 견적에는 준비금 스테이블코인의 오라클 가격과 1:1 중 사용자에게 더 적은 금액을 주는 쪽이 적용됩니다. 인정된 Underscore 볼트에는 한도, 허용 목록, 수수료가 적용되지 않고 상환 시 더 유리한 견적을 받습니다.
* 상환 금액은 총준비금이 상한입니다.

**유휴 준비금도 계속 일합니다.** 거버넌스가 수익 볼트를 지정했다면 PSM은 유휴 준비금 전액을 해당 볼트로 보내고 상환에 필요할 때 회수합니다.

### 3. Underscore를 통한 수익 및 유동성

Endaoment는 표준화된 어댑터("Legos") 레지스트리를 가진 [Underscore Protocol](https://underscore.finance/)을 통해 DeFi에 연결됩니다. 모든 통합은 수익 포지션 예치 및 출금, 스왑, 유동성 추가 및 제거, 인센티브 청구라는 같은 명령을 사용합니다. 새 통합은 레지스트리에 등록되면 사용할 수 있습니다. 각 운용은 거버넌스가 최소 수령량 검사 등을 지정해 제출하는 별도의 트랜잭션이며, 자금이 투입되는 운용처의 위험을 그대로 가집니다.

### 4. 전략적 파트너십 프로그램

**파트너에게:** 트레저리와 함께 공동 투자하고 LP 포지션을 나눕니다.

**Ripe에게:** 희석 없이 더 깊은 GREEN 시장과 새로운 수익원을 확보합니다.

작동 방식은 다음과 같습니다. 파트너 자산이 트레저리로 들어오고, 같은 가치의 GREEN과 페어를 만듭니다. 트레저리 GREEN을 먼저 사용하고 나머지를 발행합니다. LP 토큰은 50/50으로 나누며, 풀이 받지 않은 발행 GREEN은 소각합니다.

## 프로토콜 수익이 가는 곳

### 수익 배분

개시 수수료와 차용자 이자는 두 곳으로 나눌 수 있습니다.

* **sGREEN 수익**: [sGREEN](../earning-and-rewards/01-sgreen.md) 보유자에게 전달됩니다.
* **거버넌스 배정**: RIPE 바이백을 위해 GREEN으로 거버넌스에 전송됩니다.

배분 비율은 거버넌스 설정이며 기본값에서는 100%가 sGREEN으로 갑니다. 프로토콜은 GREEN만 이동합니다. RIPE 바이백은 거버넌스가 별도로 실행하는 작업입니다. [RIPE 가치 축적](../governance-and-economics/01-ripe-tokenomics.md#ripe-가치-축적)을 참조하세요.

### 트레저리 수익

거버넌스가 RIPE 스테이커, sGREEN 보유자, 다음 전략 등 다른 곳으로 보내지 않는 한 Endaoment가 벌어들인 모든 수익은 트레저리에 남습니다.

## 복리 효과

트레저리는 단순한 최후의 안전망이 아니라 성장 엔진입니다.

본드가 판매될 때마다 연료가 늘어납니다. 수익을 수확할 때마다 복리로 성장합니다. Stabilizer 작업은 트레저리를 전보다 최소한 같은 수준으로 유지할 때만 실행됩니다. 다른 트레저리는 보유한 달러로 성공을 측정합니다. Endaoment는 벌어들인 달러로 측정합니다.

트레저리는 일하고 있습니다. 함께하고 계신가요?
